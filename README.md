# 下班别散架 · 可玩原型 012

静态 HTML + Canvas + Matter.js，无需安装依赖。

直接打开 `dist/index.html` 即可试玩。或在本目录运行：

```sh
python -m http.server 8765 --directory dist
```

访问 http://localhost:8765。

## 操作

- 鼠标或触屏：按住游戏画面，左右拖动小车。
- 键盘：方向键或 A / D 移动；空格开始 / 打开菜单；R 原线重试。
- 接住第一件货后，可点「来阵妖风」体验起飞与极限救货，冷却 5 秒。
- 松开手指/鼠标或最后一个方向键，丢弃旧目标并平顺制动。
- 正式路线需真实签收至少 4 件，并在尾段完成两站停稳；车货安全即可提前收工，最多 60 秒。同一波散架只扣一次机会，三次翻车结束。
- 漏接货物在投递窗口允许时按原 ID 补发，预告至少 3 秒并按距离预留挪车时间，真实接住才计签收；窗口不足会明确结束补发。已经签收的货只扶回车上，不重复计数或奖励。
- 手机随时点 ☰ 打开菜单，可切路线、开声音、看说明、跳过教学或返回大厅。声音偏好与记录仅保存在本机浏览器。

## 内容

普通路线与每日同题路线、六件物理货物、真实接货和掉落、翻车复位、险救慢动作、夸张表情、粒子、震屏、合成音效、结算与本机最佳记录。

### 012 具体练习与下一条收工线

- 全单精准章按真实签收事实记录具体货物、原单顺序及未精准原因。原线重试把该件作为练习重点，在预告和接货时再次提醒；本次未遇到、再次接偏和精准接住分别评价。旧成绩没有逐件事实时仅提示总数，不编造失误货物。
- 报告保留未投出原单与补发过期货物的具体身份和原因。投递必须在39秒截止前留够接货预告；窗口不足时本趟不再发该件，剩余总局时间用于保货和停站。签收过的货归位不会重复计精准。
- 本线毕业后优先出发到下一条未毕业普通线，预览其收章进度和目标；普通线都毕业后可挑战今日同题。原线自由跑与R键原线重试继续保留。
- 三枚正式章之前新增本线小目标：真实签收4件、停满两站、安全收工；另外保留最佳精准件数，让未拿到全准章的一趟也能取得真实单项进步。首次奖励只发一次，历史可信成绩静默折算，教学不写正式进度。
- 已有S/A成就、最高分、最快S、V11三章和固定限时继续沿用，后续失败不会清除。原物理、投递截止、评分和S条件保持原样；新反馈遵循静音和减少动态效果设置。
- 验证：引擎80项与界面246项，共326项测试通过；9组行为模型的结果、用时和前30秒物理轨迹与011一致。另通过76项受控工具检查，并在320×568浏览器验证具体货物练习、原单未投出／补发过期说明、精准单项进步、毕业推荐跳过已毕业路线、失败局小目标及旧S保留。受控终局持续标注，不能视为自然通关或真人成功率；本地测试记录已恢复，QA工具不随游戏交付。

### 011 三枚章与明确反馈

- S时间关直接显示本关剩余时间，总局仍有独立60秒上限；临近截止显示小数余量，暂停与结算使用同一百分秒标准。仅限时超出不取消普通S评级，翻车或扶正才失去本趟S资格。
- 原线练习区分尚未练到、实际尝试失败、已取得单项进步。未投递的旧货、尚未进入的旧停站或靠站环节使用中性说明，不再当作这次又失败；下一趟建议仍优先真实致命原因。
- 原单未投出、漏接后补发已过期、已签收货物归位分别统计与说明；分类只影响反馈，不改变投递截止、物理、签收或计分。
- 每条路线有S章、限时章、全单精准章，集齐三枚即本线毕业，可换线继续收章或原线自由跑。新章可同局多项达成，有独立印章和短音阶；既有S庆祝、静音与减少动态效果偏好继续生效。
- 限时目标只固定一次，为初始可信S用时向前的整数秒，最低42秒；已有45.98秒S仍对应45秒目标，达成后不再继续减秒。新取得首个S只记录基线，不凭空完成刚创建的时间关；全单精准章需S并真实签收六件、精准六件。
- 历史S和最快S沿用，阶段记录按路线／每日题分开；历史成绩仅按可确认字段折算，已有阶段不会因刷新、更慢S、A级或失败倒退。教学不写正式章，原线重试仍保留同一题。
- 验证：引擎73项与界面201项，共274项测试全部通过。320×568手机视口真实键盘试玩完成两站，核实S余秒、原单未投出、单项进步与旧S保留；另以明确标注的本地受控终局验证45秒边界、全准阶段独立获章、三章毕业和尚未练到鱼，受控结果不计为自然通关。测试后已恢复本端口原始记录，QA工具不随游戏交付。

### 010 本趟目标与练习进步

- 救货交接增加运动支撑预测，并在交接后继续检查风险；支撑失效会撤销停站提示。提示缓冲减少短暂的“准备停站”闪回，静止稳定边缘仍能解除救货。路线、碰撞、抓地、计分、真实投递与扶正规则保持原样。
- 开局固定本趟已有S限时目标，复用HUD右侧状态位显示目标、总精准件数和资格；暂停菜单提供完整条件。超过限时只表示限时挑战未达，仍可争取本趟S级。
- 结算先评价开局固定的目标，再显示下一关。成绩用百分秒显示，区分44.98秒达成45秒关与45.02秒未达。A级即使用时达标，也会解释尚未保持S；首次取得可计时S只记录用时，不凭空宣布过关。
- 原线练习按本趟实际证据显示接货、精准和停站进展；暂时接妥只提示继续保货，实际收工后再评价是否保住。再次掉落、补发和扶正会影响对应结论，旧事故事实不会持续冒充当前不足。
- 继续沿用008最佳/最近局、009S用时与回访偏好、永久S/A成就；本趟评级与历史最高评级独立。较慢S、A级和失败不放宽已有时间目标，原线/日期和教学记录继续隔离。
- 验证：69项引擎＋155项界面回归通过。9条行为模型及1个对照均完成，所查短交接和危险反向窗口均消除；原41.87秒S模型保留。另经320px浏览器真实接货验证精准达标反馈，受控终局区分44.98秒S达成、45.02秒S未达限时与44秒A级未达S条件。受控终局不是自然通关，模型不代表真人成功率。

### 009 提示连续与原线练习

- 救货指令在货物连续安全0.2秒后交回新任务，减少救货与停站反复切换。运动中的支撑不足不会当作已经稳住；越出可追边缘时明确提示到边刹住、保住其余货。只调整提示交接，真实投递、扶正、碰撞和安全判定保持原规则。
- 记住最后选择的正式模式与普通路线；跳过教学后即保存，回访不要求先完成教学。旧版已有正式记录的玩家直接进入正式路线；手动重练教学不会覆盖正式偏好。
- S级用时以百分秒保存，每条路线／每日题分别保留已记录的最快S。结算、大厅和刷新后的挑战统一使用这个基准，较慢S、A级和失败不会放宽目标。历史S徽章沿用；没有可信S用时的旧徽章不会被编造一个时间。
- 原线重试会在开局显示一个上趟重点，并在对应货物或停站出现时再提示；局中主动作仍按当前风险决定。事故保存实际货物ID和时间，旧记录无法区分重复货物时只作开局回顾。暂停菜单也可查看本趟重点。
- 沿用008最佳与最近局，保留全部既有S/A成就、独立S标题、紫色评级与音效。路线、计分和S判定条件未改。
- 回归：66项引擎＋129项界面检查通过。20组键盘／触屏反应模型均真实投出、签收六件并完成收工，未新增扶正；自然S模型仍可达成。模型不代表真人成功率。

### 008 主动接货与可信反馈

- 重排三线与日题落点，至少三件货的实际接触范围位于初始被动车面之外；通过真实换位接货达标。首件仍快速到达，后续预告按移动距离计算，保留55px/s轻挪手感。原线重试仍是同一道题。
- 修复扶正后清空真实松手状态的问题；同一站已实际移动并松手，归位后可继续计站。轻微短晃暂停或缓退进度，严重危险仍不计站；每个新站仍要求新的移动与松手。
- 无法在投递窗口内完成预告的补发不再承诺，显示未能签收数量；仍有后续可投货与空中接取机会时保留机会。投递结束且货物安全可提早进两站，不足四件且无机会时及时结束。
- 同一结果下出现更多翻车、更多扶正、评级下降或更慢收工，进步栏显示客观分项变化；签收增加不再自动评价为“更稳”。
- 失败和A级报告保留具体事故货物、侧向与建议；“只练某站”改为“原线重来，重点练某站”，不暗示存在独立检查点。换线前展示下一线名称和特点。
- 既有S/A成就沿用并从可证明的006/007记录补齐；008分数和最近局单独记录。当前S有独立标题、紫色评级与上扬音阶；后续失败仍保留最高S。
- 回归：61项引擎＋94项界面检查通过。20组键盘/触屏0.3/0.6秒反应模型均实际签收六件并完成两站；四线不动接货模型约19秒仅签收一件失败。模型不代表真人成功率。

### 007 整单节奏与路线差异

- 日题六件计划调整至0.8/6.5/12.5/18.5/24.5/31秒；39秒为统一末次投递窗口。普通、日题在整单投完、补发接妥、旧货稳定后都可提前进入两站，保留42秒兜底，不取消空中货的真实接取机会。
- 四件是最低目标。HUD继续显示剩余待投、空中未签收、待补发或旧货待稳；补发与后续投递并存时先提示补发。投递窗口关闭后不再承诺新投递。新增状态行后，主指令按HUD实际高度避让。
- 进步评价先检查是否从收工变失败、停站是否倒退，再比较签收和分数；退步时只显示中性事实，仍保留未收工局中确实增加停站或签收的进步。
- 三条普通线从前半程就有区别：稳稳线练基础；折返线改变落点并镜像路况方向；轻重线改变货序与节奏。大厅展示当前路线特点，原线重试保留同一题。
- 最高评级独立于最高分与最近一趟保存。较低分S级、后续失败、刷新页面都不会覆盖S；普通线按路线、日题按日期隔离。保留可从006记录确认的已获评级，007分数单独记录。
- S级仍需无翻车、无扶正、至少三次精准签收并安全收工；首次获得、结算与大厅都有反馈。
- 调整了已签收且真正受支撑货物的接触抓地和角速度阻尼，长整单更可控；空中货不被托住，快速拉车仍会翻车，险救与事故回看保留。

### 006 节奏与反馈

- 普通路线末件更早投递，所有计划已投完、没有在途或补发货、签收达标且车货稳定后，即可提早进入两站，42秒保留兜底。真实签收、每站重新移动并松手、安全到家条件继续保留。
- 静音时也能看见HUD里的风向和减速带预告，预警与唯一动作指令同时显示，不再依赖屏外说明。
- 已到接货位置时保留落点线、货物名称和等待倒计时，轻微挪动不会让整个空间提示消失；尾段状态卡改用简短状态，避免与主指令重复。
- 每条原线分别记住最近一趟，结算显示多停稳、多签收、少翻车或更快等实际进步；每趟都会更新，独立于历史最高分，教学与其他路线不混比。
- 006独立纪录，保留教学完成、声音和所选路线。

### 005 审查修复

- 投递已结束且场上剩余未签收货也无法补足4件时，直接报告签收未齐，不再让必败局等待到60秒；仍在落下、足以补齐的货保留真实接取机会。
- 默认键盘横移速度从110降至55px/s，按住轻挪、到位松手。触屏仍按实际拖动目标操控，保留稳车与救货的物理反应。
- HUD、菜单、底部、R和结算的重试均保留原路线；每日同题重试保留本局日期。只有明确点「换条线」才切换下一条轻松收工线。
- 每条轻松收工线分别记录，每日按日期记录；005独立保存纪录，保留教学完成和声音偏好。
- 失败报告按真实签收、最后失误、停站缺口给出一个具体目标；冲S明确要求无翻车、无扶正、至少3件精准签收。
- 到站反馈区分尚未到位、需要松手、车速未停、具体哪件货未稳、正在计站和归位中，显示停稳进度。
- 手机结算优先展示本次失误、一个改进目标与事故回看，详细统计可展开；底部固定提供原线重试、换线、大厅及菜单。

### 004 审查修复

- 手机菜单贯穿大厅、局中与结算，打开时暂停物理并清除旧操控；退出专注恢复顶栏，返回大厅取消尚未出现的结算回调。
- 终点先检查签收、两站和车货安全。末秒翻车或归位中会进入最多 2 秒的靠站检查，不再空车判成功；失败报告区分未接齐、未停完整与靠站不稳。
- 减少后半程投递空窗，长时间救货不稳时扶正已签收货；扶正次数单列，不算新签收、精准或险救奖励。
- 42 秒开启两站收工：按亮区顺序挪车，到位松手停稳。两站合计 200 分，安全完成可提前结束，按剩余时间另奖分。
- 轻松路线三种收工线轮换，每日同题仍按日期固定。报告展示两站、实际用时、两项奖金及下一趟技巧目标。
- 004 使用独立正式纪录，保留已完成教学状态。新手仍是不限时三步实际操作，菜单可中途跳过。

### 003 审查修复

- 真制动：松手后不会继续追逐旧目标，暂停与取消拖动也会清理操控。
- 全场只显示一个动作指令；先救旧货，冲突的新货保留排队，到安全后再预告投递。未签收货物不生成分数，未完成 4 件运送不会仅凭存活判为成功。
- 手机按可用宽度呈现游戏，允许纵向滚动；开局自动聚焦游戏，HUD 和底部固定工具都可重开。主指令 15px、落点及任务至少 12px，替代随画布缩成约 5px 的落点字。
- 新手三步独立练习：先实际挪车接饼，再带货换位并明确松手停稳，最后主动接回弹起的饼。不限时，不扣机会，可跳过或重练，完成后进入正式路线，教学不写正式纪录。
- 补发显示为接货预告，归位说明放入当前指令的副文案，避免遮挡车身。精准连签用准确名称呈现。
- 003 使用独立正式纪录键，避免新旧控制/路线和通关规则混合比较。

### 002 改进（版本记录）

- 首件教学保留宽容，后续货物提前 2.2 秒预告固定世界落点；虚线显示接货参考位置，货物不会追着小车投放。
- 增加质量加权重心提示、单件滑落风险标记与侧风流线，让轻挪和救货有判断依据。
- 用车中心接货且移动足够慢可获精准奖励；连续精准签收递增加分，每趟目标为精准接住三件。系统复位不算玩家签收，自动蹦跳不算主动险救。
- 事故记录实际物件、方向与漏接/滑落事实。结算可回看最后一次事故前约 2.8 秒的真实货物/车身姿态；回看不改变成绩和生命。
- 增加本趟评级、最长连稳、距个人纪录与下一趟目标。002 使用独立本机纪录，避免与旧计分直接比较。
- 每日同题按 Asia/Shanghai 日期生成；相同日期使用相同路线，可在测试中显式传入日期种子。
- 提高 Canvas 清晰度，降低键盘基础横移速度，支持系统减少动态效果设置。
