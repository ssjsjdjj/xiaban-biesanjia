# 惊雷 · 断潮

原创竖屏 Canvas 动作原型，默认三位首领连续挑战，每场最多 60 秒。剩余气血进入下一境，胜场少量恢复，场间选择调息或持续强化。手机采用左摇杆、右侧斩击／格挡／闪避，电脑支持键盘；浏览器与微信入口共用引擎和绘制模块。

| 首领与场景 | 应对方式 |
| --- | --- |
| 逐影剑客 · 听雨庭 | 弹反金色刀锋，等短连段末刀后反攻 |
| 鸣弦游猎 · 青篁渡 | 横移避三线箭道，跟随换位；弹反回箭，收弓时近身 |
| 负岳巨像 · 烬火炉 | 两次满蓄重斩碎甲，利用八秒弱点；闪过震环和地火 |

胜场自动恢复最多 8 点气血，整备可再恢复最多 32 点，或选择伤害强化 12%（叠至 24%）。整备冻结计时，失败或重新挑战从第一境开始。挑战处决恢复最多 10 点，保留的单场练习恢复最多 14 点；两种模式分别记录最佳战绩。

续招采用单槽缓存，只保留下一刀，避免连续点按堆成长队列。近身攻击使用短步追身，后退走位不会被自动拉回；横向蓄力时刀锋保持朝向首领。闪避中的续招会在动作结束后接出，命中顿帧保留防御冷却的真实节奏。

## 立即运行

用现代浏览器打开 `dist/index.html` 即可试玩，无运行时依赖。也可以用 Python 3 启动本地静态预览：

```sh
npm run preview
```

然后访问 `http://127.0.0.1:4185`。声音默认关闭，可在界面开启；特效可切换为柔和。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 走位 | WASD / 方向键 | 左下摇杆 |
| 轻斩、三连 | 轻按 J | 轻点「斩击」 |
| 蓄力重斩 | 按住 J，再松开 | 按住「斩击」，再松开 |
| 格挡、弹反 | K | 点「格挡」 |
| 闪避 | 空格 | 点「闪避」 |
| 破防处决 | E / J | 点「处决」 |
| 暂停 | P / Esc | 暂停按钮 |

切到后台会自动暂停。战绩与声音、特效偏好保存在当前浏览器。

## 构建与验证

使用 Node.js 22 或更新版本；CI 使用 Node.js 24。项目没有 npm 依赖，不需要先安装依赖。

在包含本 README 的目录运行以下命令。

```sh
npm test
npm run build
npm run simulate
npm run simulate:session
npm run simulate:challenge
```

`npm test` 执行连续挑战、场间选择、计分及当前战斗的核心、操作手感、UI、微信触控、动画、变招公平性与离线打包检查。`npm run simulate` 运行带反应延迟、误差和漏操作的控制模型；`npm run simulate:session` 在同一个游戏实例中连续完成多局，比较轻斩、蓄力、混合、抓收势和绕行策略。`npm run simulate:challenge` 比较整轮三境的不同策略、反应误差与关间决策。模拟只通过正常操作推进战斗，不直接修改血量或时间；结果不能当作真人胜率或留存数据。

`npm run build` 会更新静态资源指纹、同步微信共用模块，并生成内嵌代码的单文件 HTML、浏览器源码、微信源码与试玩说明。设置 `THUNDERBLADE_OUTPUT_DIR` 可以指定输出目录；未设置时使用构建脚本中约定的交付目录。GitHub Actions 将输出放在临时目录，不提交生成包。

当前回归入口集中在 `package.json` 的 `test` 脚本中；连续多局模拟使用单独命令，便于按需要检查重玩节奏。

## 源码结构

| 路径 | 内容 |
| --- | --- |
| `dist/engine.js` | 战斗规则、输入缓冲、首领刀路与连段 |
| `dist/duel-art.js` | 人物、首领动作、预警与打击特效 |
| `dist/ui.js` | 浏览器输入、界面、音效与本机记录 |
| `dist/index.html` / `dist/style.css` | 自适应布局与双拇指操作区 |
| `wechat/game.js` | 微信 Canvas 与多指触控适配 |
| `build-deliverables.cjs` | 单文件试玩与源码包构建 |
| `mobile-feel-sim.cjs` | 带失误的可重复对局模拟 |
| `replay-session-sim.cjs` | 同一实例中的连续多局与不同打法对比 |
| `gauntlet-session-sim.cjs` | 整轮三境、打法差异与高失误策略模拟 |
| `gauntlet-checks.cjs` | 连续挑战生命周期、箭道与破甲边界 |
| `feel-regression-checks.cjs` | 走位、追身、续招与打击节奏回归探针 |

`dist/` 可以直接部署到静态托管。

## 微信小游戏

构建后，在微信开发者工具中导入 `wechat/`，项目类型选择小游戏。`project.config.json` 使用游客占位 AppID；实际开发预览需要自己的小游戏 AppID。微信入口共用战斗和动画，当前分层合成音效用于浏览器版。

微信入口已进行触控和安全区 mock 检查，尚未完成微信真机验证或提审；真实设备仍需检查系统菜单胶囊、性能和触感。原型未接入登录、支付、广告或云存档。

## 素材与许可

人物、首领、场景、动作、特效与音效均为原创程序实现，未使用《沧元图》人物、剧情或素材。仓库尚未指定开源许可证。
